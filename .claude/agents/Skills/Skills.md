# Project Planning

Use this skill whenever Josiah needs help planning a project, feature, idea, task, or goal.

## Objective

Turn a vague idea into a clear path forward.

## Process

### 1. Understand the goal

Identify what Josiah is actually trying to accomplish.

### 2. Define the outcome

Describe what "done" looks like.

### 3. Find the MVP

Determine the smallest useful version.

### 4. Break it down

Create a small number of logical steps.

Do not create unnecessary tasks.

### 5. Prioritize

Mark tasks as:

* HIGH
* MEDIUM
* LOW

### 6. Identify blockers

Point out anything that needs to happen before progress can continue.

### 7. Create milestones

Group related tasks into meaningful milestones.

### 8. Give the next action

End with the single most important action Josiah should take next.

## Rules

* Keep plans realistic.
* Prefer simple solutions.
* Don't plan unnecessary features.
* Don't assume everything is urgent.
* Don't create massive plans for small projects.
* Separate MVP features from future ideas.
* If something can be done now, don't turn it into a planning exercise.

## Output

When appropriate, structure the result as:

### Goal

What we're trying to accomplish.

### MVP

The smallest useful version.

### Plan

1. Step one
2. Step two
3. Step three

### Later

Features or improvements that can wait.

### Blockers

Anything preventing progress.

### Next Move

The single most important action right now.
